# Cyber Security Guidelines Reflection

**What security measures do you currently follow, and where can you improve?**
I currently use strong, complex passwords for my primary accounts and have 2FA enabled on critical platforms like GitHub and Google. However, I can improve by ensuring I never reuse passwords across lesser-known services and by fully migrating to a dedicated password manager.

**How can you make secure behaviour a habit rather than an afterthought?**
I can build secure habits by integrating them directly into my workflow. For example, using a password manager browser extension makes generating strong passwords frictionless, and setting an aggressive auto-lock timeout on my OS ensures security happens automatically if I forget.

**What steps will you take to ensure your passwords and accounts are secure?**
I will audit my work-related accounts to ensure every single one uses a unique, randomly generated password stored in a password manager. Additionally, I will enforce app-based 2FA (like Google Authenticator or Authy) rather than relying on SMS-based 2FA.

**What would you do if you suspected a security breach or suspicious activity on your account?**
I would immediately revoke active sessions, change the compromised password from a secure device, and immediately notify the Focus Bear IT/security team to investigate potential unauthorized access to company repositories or servers.

**Task: Document one new cyber security habit you will follow at Focus Bear.**
I will make it an automatic physical habit to manually lock my computer (using `Windows Key + L`) every single time I step away from my desk, even when working securely from home.
