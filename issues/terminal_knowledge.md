# Terminal Client Setup and Knowledge Reflection

**Which terminal client did you choose? Why?**
I chose to use the **Integrated Terminal in Visual Studio Code** running **PowerShell**. Since I am developing on a Windows machine, PowerShell provides a robust and powerful command-line shell. Using it directly inside VS Code is highly efficient because it prevents me from having to constantly context-switch between my code editor and a separate external terminal window. 

**What customizations (if any) did you make?**
I have kept the customizations relatively clean and minimal to focus on mastering the core CLI commands. However, I rely on VS Code's integrated UI themes and font settings, which automatically provide syntax highlighting for my terminal outputs, making it much easier to distinguish between file paths, git statuses, and error messages.

**What was the most useful command you learned today?**
One of the most useful fundamental commands is `code .` (when used in a standalone terminal), which instantly opens the current directory in a new VS Code window, saving a lot of time compared to navigating through the graphical file explorer. In the context of my daily workflow, commands like `cd` (to change directories) and the `git` sequence are the ones I execute the most to navigate the repository.
