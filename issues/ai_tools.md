# AI Tools for Development Reflection

**Which AI tools did you try?**
I integrated conversational AI assistants (such as ChatGPT and Gemini) directly into my workflow alongside my standard VS Code setup. I also explored how these tools compare to inline code-completion extensions like GitHub Copilot.

**What worked well? What didn't?**
The AI worked exceptionally well as an interactive tutor and pair programmer. It was brilliant at explaining complex architectural concepts (like NestJS Dependency Injection or Docker networking) and generating repetitive boilerplate code (like standard CRUD controllers or markdown reflections). 
However, what didn't work well was relying on the AI to blindly write code without providing it with exact context. If I didn't explicitly share the structure of my custom DTOs or environment variables, the AI would generate generic code that required manual fixing to fit my specific project architecture.

**When do you think AI is most useful for coding?**
AI is most incredibly useful during the initial stages of learning a new framework or setting up a project, as it dramatically reduces the time spent searching through official documentation or Stack Overflow. It is also highly valuable for debugging cryptic terminal errors, scaffolding repetitive tests, and writing clear, formatted documentation quickly. It excels at augmenting a developer's speed, rather than replacing the core problem-solving logic.
