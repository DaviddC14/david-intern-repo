# VS Code Productivity & Shortcuts Reflection

## Top 10 Useful VS Code Shortcuts

**Editing**
1. **Multiple Cursors (Next Match):** `Ctrl + D` - Selects the word at the cursor, or the next occurrence of the current selection. Essential for quick, synchronized renaming.
2. **Multiple Cursors (Arbitrary):** `Alt + Click` - Inserts an additional cursor exactly where you click.
3. **Move Line Up/Down:** `Alt + Up/Down Arrow` - Moves the current line (or selected block) up or down without needing to cut and paste.
4. **Copy Line Up/Down:** `Shift + Alt + Up/Down Arrow` - Duplicates the current line above or below.

**Navigation**
5. **Quick Open:** `Ctrl + P` - Opens a search bar to instantly navigate to any file in the project by typing its name.
6. **Global Search:** `Ctrl + Shift + F` - Searches for a specific string across all files in the entire workspace.
7. **Toggle Sidebar:** `Ctrl + B` - Hides or shows the Explorer sidebar to maximize screen real estate for coding.

**Terminal Commands**
8. **Toggle Terminal:** `Ctrl + \`` (Backtick) - Opens or hides the integrated terminal panel.
9. **New Terminal:** `Ctrl + Shift + \`` - Opens a new, additional terminal tab.

**Debugging**
10. **Start/Continue Debugging:** `F5` - Launches the debugger or continues execution until the next breakpoint.

---

**Which shortcuts do you think will be the most useful in your daily work?**
The most useful will definitely be `Ctrl + P` (Quick Open) and `Ctrl + D` (Multiple Cursors). When working on a modular backend like NestJS, `Ctrl + P` makes jumping between Controllers, Services, and Modules incredibly fast without touching the mouse. `Ctrl + D` is invaluable for refactoring variable names or modifying multiple similar DTO properties simultaneously.

**How can keyboard shortcuts improve your productivity?**
Keyboard shortcuts keep my hands on the keys, completely eliminating the micro-delays and context-switching associated with reaching for the mouse, navigating menus, and clicking. Over the course of a day, these saved seconds compound into significant time savings, allowing me to maintain a state of "flow" and execute refactoring or file navigation at the speed of thought.
