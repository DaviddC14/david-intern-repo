# AI Coding Tools Learning Reflection

**Which tool you used**
I decided to explore **Cursor** (an AI-powered code editor built on top of VS Code) for this exercise, as it integrates seamlessly with my existing extensions and keyboard shortcuts.

**What you used it for**
I used the AI assistant primarily for two tasks: **Understanding existing code** (specifically, breaking down how NestJS Dependency Injection wires up Controllers and Services under the hood) and **Writing documentation** (formatting onboarding reflections and summarizing technical concepts).

**What it helped with**
It was incredibly helpful for instantly explaining complex framework boilerplate without having to leave the IDE or context-switch to a web browser. It also drastically sped up the documentation process by generating well-structured Markdown based on simple conversational prompts.

**What it struggled with**
The AI sometimes struggled with broader, project-wide context. If I asked it to explain or refactor a piece of code that heavily depended on a custom interface located in a completely different, closed file, it would sometimes "hallucinate" or guess the structure incorrectly. I learned that AI tools require precise prompting and explicitly attaching the right context files to be truly effective.
