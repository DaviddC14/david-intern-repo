# Kanban Workflow Reflection

**How does Kanban help manage priorities and avoid overload?**
Kanban visualizes the entire workflow, making bottlenecks immediately obvious. By implementing Work-In-Progress (WIP) limits, it prevents team members from starting new tasks before finishing current ones, ensuring a steady, manageable flow of work rather than an overwhelming backlog.

**How can you improve your workflow using Kanban principles?**
I can improve my workflow by strictly adhering to WIP limits and pulling new backend tasks only when I have fully completed my active assignments. This will help me focus entirely on one feature or bug fix at a time, improving overall code quality.

**Identify one way you can improve task tracking in your role:**
As a Backend Developer Intern, I can improve task tracking by consistently linking my commits and pull requests directly to their corresponding Kanban cards. This ensures that the QA team and project managers have real-time visibility into the status of API updates and database schema changes without needing to ask for manual updates.
